About SonicNodes

Project

SonicNodes v13.4 is an interactive web application that visualizes the relationships between musical genres as a dynamic isomorphic graph. It uses network physics (force-directed graph) to create visual constellations where each node represents a musical genre, and connections show influences and mutual relationships between genres.

The application allows you to explore the architecture of the modern musical universe with more than 90 genres organized hierarchically and connected through cross-relations (bridges) that represent musical fusions.

Key Features

Three depth levels (Macro / Sub / Artist), real-time iTunes audio previews, predictive universal search, Time Machine for historical hits, mood & energy filtering, bilingual interface (ES/EN), light/dark themes, and Spotify integration.
